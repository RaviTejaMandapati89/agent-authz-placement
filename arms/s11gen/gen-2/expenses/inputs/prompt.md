Write the access policy for one use case, in Cedar.

1. Read requirements.md. It is the only statement of what the policy must do.
2. Read schema.json. It is the Cedar schema the policy will be validated against.
3. Read gateway_facts.md. It lists the entity, action and context attribute
   names the gateway passes with each request, and how a refusal is reported.
4. Write the complete policy to policy.cedar in the current directory.

Write nothing else and read nothing else. Reply "done" when policy.cedar is written.
